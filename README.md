# Prescription Management System

This project is a web application built with React and TailwindCSS to manage prescriptions. It includes features such as opening a modal dialog for adding prescriptions, dynamically handling modal content, and ensuring responsive design for mobile views.

---

## Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Material Tailwind**: UI components built with TailwindCSS and React.
- **TailwindCSS**: Utility-first CSS framework for styling.
- **JavaScript (ES6+)**: Core language for React and the application logic.

---

## Project Setup

### Prerequisites

Ensure you have the following installed on your system:

- **Node.js** (v14.x or later)
- **Yarn** or **npm**
- **Git** (for version control)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Camairetech-Technology-Training/CamyCare.git
   cd CamyCare
   ```

2. Install dependencies:
   ```bash
   yarn install
   ```
   or
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   yarn dev
   ```
   or
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.
